# Production font asset

`LXGWWenKaiGB-Medium-v1.522.ttf` is the unchanged Medium TTF from the official
[LXGW WenKai GB v1.522 release](https://github.com/lxgw/LxgwWenKaiGB/releases/tag/v1.522).

- Upstream project: <https://github.com/lxgw/LxgwWenKaiGB>
- License: SIL Open Font License 1.1
- SHA-256: `b885c51ec0d3f325974013801dfcefda1a9ba0bf385c607cf5f2582dafa2e5ab`
- Local CSS family alias: `SeanLab WenKai GB Production`

The local CSS alias is an application identifier only. The font binary, family metadata, and upstream filename are
not modified or renamed inside the font. `OFL-1.1.txt` is distributed beside the binary.

The production selector checks a frozen codepoint coverage map generated by
`scripts/build-typography-font-coverage.py`. Do not replace the font file without updating its version, checksum,
coverage map, license evidence, policy tests, and static review evidence.
