# Open-source edition

This repository ships code, schemas, local UI assets, creator-neutral review placeholders, and three background-only
cover template families in landscape and portrait formats.

It does not ship a creator portrait, a fixed channel greeting, a fixed bumper, private recordings, project data, or a
pre-populated people/image library. To make a cover, import your own transparent portrait cutout as PNG or WebP;
the file remains inside the ignored local project. Confirm its rights before production use.
